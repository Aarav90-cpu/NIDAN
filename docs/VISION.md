# Vision

**Learning should adapt to the child.**

NIDAN envisions an educational environment where every student progresses at their own pace, and individual progress is prioritized over classroom ranking. Education must be accessible, resilient, and adaptive, regardless of internet connectivity or geographical location.

### Core Principles
1. **Learning before features** - Every feature must meaningfully contribute to learning or accessibility.
2. **Offline first** - The system remains fully functional and useful without continuous internet access.
3. **Student progress over ranking** - Students compete with themselves, not each other.
4. **Teacher assistance, not replacement** - Provide teachers with actionable information while leaving final decisions to educators.
5. **Small, reliable systems** - One feature that works reliably is better than ten that barely function.
6. **Honest engineering** - Project claims must match the actual implementation.
7. **Maintainability** - Software must run on modest hardware and be understandable to future developers.
