# Privacy Principles

NIDAN operates under strict data minimization and privacy-first principles. Student data is incredibly sensitive.

## Core Tenets
1. **No Public Leaderboards:** Student progress is private. There are no public rankings, "hall of fame," or competitive leaderboards that compare students against one another.
2. **Data Minimization:** We only collect data strictly necessary for the adaptive learning engine (answers, time taken, assessment scores). We do not track unnecessary behavioral analytics.
3. **Local by Default:** The student's device (T1) and the classroom hub (T2) hold the primary learning data. Synchronization to a broader cloud instance is strictly for backup and teacher analytics, and must support anonymization.
4. **No Real Names in Test Data:** Developers must NEVER use real student names, emails, or PII in examples, fixtures, or database seeds.

## Authentication & Access
- Teachers have access to aggregate classroom data and individual student progress within their assigned classes.
- Students only have access to their own progress.
